Import Bill of Quantities

Upload an Excel (.xlsx) or CSV file. The first rows must contain these column titles:

  • code, description, unit, quantity, rate (required)
  • phase (the exact name of a construction component in this project) and material (a material code) are optional
  • Rows with no quantity and no rate (headings, sub-totals) are skipped.
  • Everything is checked first. If any row has a problem, nothing is saved and the problems are listed with their row numbers.
  • Item codes that already exist in the project are rejected. Existing quantities change only through variation orders.
  • In Excel, format the code column as Text, otherwise a code like 3.10 turns into 3.1.
